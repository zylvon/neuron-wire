# Archive

This directory contains historical, superseded, or intermediate artifacts that are
preserved for reference but are not part of the current v0.3.1 release.

## Contents

- **`papers/`** — Superseded paper drafts (originally 10, consolidated to 4 credible near-term papers in `papers/`).
- **`results/`** — Intermediate/historical benchmark outputs (originally 214 files, curated to 5 representative sets in `results/`).

## Why archive instead of delete?

These files contain valuable historical context (experiment iterations, negative results,
lessons learned) that may be useful for future reference. They are not part of the
current release but are preserved in git history.
